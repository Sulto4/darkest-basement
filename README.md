# Darkest Basement

Turn-based roguelike în Unity: explorarea din **Darkest Dungeon**, cărțile din **Slay the Spire**, personajele și stilul din **The Binding of Isaac**.
Fan game privat, proiect de facultate.

- Design: [docs/GDD.md](docs/GDD.md)
- Arhitectura codului: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Ghid de artă: [docs/ART.md](docs/ART.md)

## Cum îl deschizi

1. Instalează **Unity Hub** și editorul **Unity 6000.3.26f1** (Unity 6.3 LTS), cu modulul *Windows Build Support (Mono)*.
2. Unity Hub → *Add project from disk* → folderul ăsta.
3. Deschide scena `Assets/_Game/Scenes/Main.unity` și apasă Play.
